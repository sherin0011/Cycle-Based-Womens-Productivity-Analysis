# Cycle-Based Women's Productivity Analysis

## Project Overview

This project analyzes how menstrual cycle phases and lifestyle factors influence productivity. Using a synthetic dataset of 3,000 records, the study explores relationships between sleep, stress, mood, pain levels, PCOS status, work mode, and productivity scores.

The project combines Data Analytics, Machine Learning, and Data Visualization techniques to identify key productivity drivers and build predictive models.

---

## Objectives

- Analyze productivity patterns across menstrual cycle phases.
- Identify factors affecting productivity.
- Perform Exploratory Data Analysis (EDA).
- Build machine learning models to predict productivity scores.
- Create interactive visualizations and dashboards.

---

## Dataset Information

The dataset contains 3,000 synthetic records with features such as:

- User ID
- Age
- Cycle Phase (Menstrual, Follicular, Ovulation, Luteal)
- PCOS Status
- Cycle Length
- Sleep Hours
- Stress Level
- Mood Score
- Pain Level
- Energy Level
- Focus Level
- Work Mode (Remote, Hybrid, In-Office)
- Productivity Score
